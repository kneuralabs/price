02
Set Your Rate Card
Edit the hourly rate for each of the 7 roles. Every downstream number — effort costs, blended rates, and client fees — updates live as you type.
03
Tune the Effort Matrix
Enter hours per module per role across the 11 × 7 grid. Cost derives automatically from the Rate Card. Grand totals appear in the footer row.
04
Build & Export the Quote
Toggle modules on/off to scope the engagement. Slide margin and discount. The client price box updates instantly. Hit Export to copy to clipboard.
Inputs
What you control
  • Hourly rate for each of the 7 roles
  • Hours per module & role (11 × 7 matrix)
  • Which modules are in scope (toggles)
  • Margin % — target fee above cost
  • Discount % — client-facing adjustment
Outputs
What gets calculated
  • Blended rate across all roles
  • Internal cost per module & role
  • Client fee with margin applied
  • Effective $/hr for selected scope
  • Clipboard-ready quote summary
Note
All data lives in-browser — nothing is sent to a server. Refreshing the page resets everything to defaults. Work through pages in order (02 → 03 → 04) for best results. Changes on any page recalculate all others instantly.
